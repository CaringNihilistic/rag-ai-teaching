## 📌 Overview

This project is a fully local RAG (Retrieval-Augmented Generation) system
that acts as a personal AI tutor for Machine Learning and Deep Learning.

Ask any ML/DL question and get:
- ✅ A detailed explanation generated by **LLaMA 3.2**
- ✅ Relevant **YouTube video links** with exact timestamps
- ✅ Context pulled from **industry-standard textbooks**
- ✅ Everything runs **100% locally** — no OpenAI API needed

## 🧠 How It Works
```
┌─────────────────────────────────────────────────────┐
│                   DATA INGESTION                    │
│                                                     │
│  YouTube Playlists          PDF Textbooks           │
│  (241 lectures)             (2 books)               │
│        ↓                         ↓                  │
│  Whisper GPU              pypdf chunking            │
│  Transcription            (180 words, 30 overlap)   │
│  (120-word chunks)                ↓                 │
│        └──────────── All Chunks ──┘                 │
└─────────────────────────────────────────────────────┘
                        ↓
┌─────────────────────────────────────────────────────┐
│                   VECTOR INDEXING                   │
│                                                     │
│     Ollama nomic-embed-text (768-dim vectors)       │
│                    ↓                                │
│         FAISS IndexFlatIP (cosine similarity)       │
└─────────────────────────────────────────────────────┘
                        ↓
┌─────────────────────────────────────────────────────┐
│                   QUERY PIPELINE                    │
│                                                     │
│  User Question                                      │
│       ↓                                             │
│  Keyword Filter → Semantic Search (FAISS)           │
│       ↓                                             │
│  Top chunks (videos + books) retrieved              │
│       ↓                                             │
│  LLaMA 3.2 generates answer with context            │
│       ↓                                             │
│  Answer + YouTube links with timestamps returned    │
└─────────────────────────────────────────────────────┘
```

## 🚀 Setup & Installation

### Prerequisites
- Python 3.10+
- NVIDIA GPU with CUDA (for Whisper transcription)
- [Ollama](https://ollama.com) installed and running

### 1. Clone the repo
```bash
git clone https://github.com/YOUR_USERNAME/rag-ai-teaching.git
cd rag-ai-teaching
```

### 2. Install dependencies
```bash
pip install -r requirements.txt
```

### 3. Pull Ollama models
```bash
ollama pull nomic-embed-text
ollama pull llama3.2
```

### 4. Add your data
```
data/audios/     ← ML lecture audio files (.wav / .mp3)
data/audios_1/   ← DL lecture audio files
data/Books/      ← PDF textbooks
```

---

## ⚙️ Running the Pipeline

> Run once to build the full knowledge base. Takes several hours
> on first run due to Whisper transcription and embedding generation.
```bash
python pipeline/01_extract_video_urls.py       # Pull YouTube URLs
python pipeline/02_json_playlist_creater.py    # Fix playlist JSON
python pipeline/03_extract_audios.py           # Transcribe audio (GPU)
python pipeline/04_extract_books.py            # Chunk PDF books
python pipeline/05_diaganosing_metadata.py     # Build initial FAISS index
python pipeline/06_build_faiss_index.py        # Fix video URLs (fuzzy match)
python pipeline/07_save_video_embeddings.py    # Backup video embeddings
python pipeline/08_merge_metadata.py           # Merge videos + books
python pipeline/09_diagnostic_text_on_metadata.py  # Verify metadata
python pipeline/10_clean_metadata.py           # Remove duplicates
python pipeline/11_add_book_embeddings.py      # Add book embeddings
python pipeline/12_rebuild_index_with_titles.py    # Rebuild with titles
python pipeline/13_swap_the_index.py           # Activate final index
```

---

## ▶️ Launch the App

Make sure Ollama is running, then:
```bash
python app.py
```

Open your browser at **http://127.0.0.1:5000** 🎉

## 🛠️ Tech Stack

| Layer | Technology |
|---|---|
| Transcription | OpenAI Whisper (GPU, base model) |
| Embedding | Ollama `nomic-embed-text` (768-dim) |
| Vector Search | FAISS `IndexFlatIP` (cosine similarity) |
| LLM | Ollama `llama3.2` |
| Backend | Flask |
| Frontend | Vanilla JS + CSS (dark mode support) |
| PDF Parsing | pypdf |
| Video Download | yt-dlp |

---

## ⚠️ Important Notes

- `data/` and `models/` are **gitignored** — run the pipeline to
  regenerate them locally after cloning
- Whisper requires a **CUDA-capable GPU** (tested on RTX 3050 4GB)
- Pipeline saves **checkpoints** automatically — safe to interrupt
  and resume at any step
- All inference is **100% local** via Ollama — no API keys required
